# ☁️ Azure Free Account

An Azure account can help you explore services referenced in SC-900, but
it is **optional** for this course.

## 🎯 Why Use Azure?

SC-900 references Azure services such as:

``` text
Virtual Networks
Network Security Groups
Azure Firewall
DDoS Protection
Azure Bastion
Azure Key Vault
Azure Policy
Azure RBAC
Defender for Cloud
Microsoft Sentinel
```

Seeing these services in the portal can make them easier to remember.

## 🆓 Current Free Account

Microsoft currently advertises an Azure free account for eligible new
customers with a **\$200 credit for 30 days**, free monthly amounts of
20+ popular services for 12 months, and free monthly amounts of 65+
services. Offers can change, so verify the current terms before signing
up.

[Azure Account
Options](https://azure.microsoft.com/en-us/pricing/purchase-options/azure-account)

## ⚠️ Cost Warning

Azure contains paid services. Before deploying anything:

``` text
CHECK PRICE
    ↓
UNDERSTAND RESOURCE
    ↓
CREATE ONLY WHAT YOU NEED
    ↓
DELETE WHEN FINISHED
```

Do not assume every Azure resource is free. If you move to
pay-as-you-go, usage beyond included free amounts can generate charges.

## 🧪 SC-900 Recommendation

For SC-900, portal familiarity is more important than building a large
lab.

``` text
OPEN AZURE PORTAL
    ↓
SEARCH FOR A SERVICE
    ↓
EXPLORE ITS OPTIONS
    ↓
CONNECT IT TO THE LESSON
```

Never experiment in an employer's production subscription without
authorization.
