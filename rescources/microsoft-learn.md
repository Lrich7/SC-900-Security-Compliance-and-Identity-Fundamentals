# 🟦 Microsoft Learn --- SC-900

Microsoft Learn should be the **primary external learning resource**
used with this repository.

It provides official Microsoft training, certification information,
study guides, documentation, and exam-preparation resources.

## 🎯 Why Microsoft Learn?

Microsoft products change frequently. Use Microsoft Learn to check:

``` text
Current Product Names
Current Features
Current Exam Objectives
Current Documentation
Current Training
```

## 📘 SC-900 Areas

The SC-900 curriculum is organized around:

``` text
Security, Compliance & Identity Concepts
Microsoft Entra
Microsoft Security Solutions
Microsoft Compliance Solutions
```

Focus on:

