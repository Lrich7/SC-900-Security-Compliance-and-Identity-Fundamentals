# 🛡️ Microsoft Security Resources

This page provides a simple map of the Microsoft security ecosystem used
throughout SC-900.

## 🧠 The Big Picture

``` text
MICROSOFT ENTRA
→ Identity & Access

MICROSOFT DEFENDER
→ Threat Protection

MICROSOFT SENTINEL
→ Security Operations

MICROSOFT PURVIEW
→ Data Security & Compliance
```

## 👤 Microsoft Entra

SC-900 topics include users, groups, external identities,
authentication, MFA, passwordless, Conditional Access, roles, Identity
Protection, PIM, Access Reviews, and Identity Governance.

[Microsoft Entra
Documentation](https://learn.microsoft.com/en-us/entra/)
