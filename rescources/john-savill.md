## ⚠️ Watch the Version

Microsoft certification objectives and product names change. Older
videos can contain older exam objectives, portal screens, product names,
or retired features.

Example:

``` text
Azure Active Directory
        ↓
Microsoft Entra ID
```

Prefer the newer **V2** SC-900 cram over the older retired version.

## 📅 2026 Exam Note

Microsoft periodically updates SC-900. At the time this resource was
prepared, Microsoft listed an update to the English SC-900 exam for
**October 21, 2026**.

Always compare video coverage with the current official study guide.

[Current SC-900 Study
Guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/sc-900)
