# 📖 Recommended Reading --- SC-900

This page contains additional reading for learners who want to go beyond
the core SC-900 lessons.

You **do not need to read everything here before taking the exam**.

## ⭐ Start Here --- SC-900 Study Guide

The official study guide should be the first external resource you check
when preparing for the certification.

[Microsoft SC-900 Study
Guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/sc-900)

Use it to verify the current exam objectives before exam day.

## 🔐 Zero Trust

Focus on:

``` text
Verify Explicitly
Use Least Privilege
Assume Breach
```

[Microsoft Zero Trust
Guidance](https://learn.microsoft.com/en-us/security/zero-trust/)

## 👤 Microsoft Entra

Useful after Lessons 03--08.

Explore authentication, Conditional Access, Identity Protection,
Identity Governance, RBAC, and external identities.

[Microsoft Entra
Documentation](https://learn.microsoft.com/en-us/entra/)

## ☁️ Azure Security Fundamentals

Useful after Lessons 09--10.

Explore shared responsibility, network security, identity and access,
data protection, and threat protection.

[Azure Security
Fundamentals](https://learn.microsoft.com/en-us/azure/security/fundamentals/)

## 🛡️ Microsoft Defender

Useful after Lessons 10--12.

Explore Defender for Cloud, Endpoint, Office 365, Identity, Cloud Apps,
and Defender XDR.

[Microsoft Defender
Documentation](https://learn.microsoft.com/en-us/defender/)

## 📡 Microsoft Sentinel

Useful after Lesson 13.

Focus on SIEM, SOAR, data connectors, analytics, incidents, hunting,
automation, and playbooks.

[Microsoft Sentinel
Documentation](https://learn.microsoft.com/en-us/azure/sentinel/)

## 🏷️ Microsoft Purview

Useful after Lessons 14--16.

Explore Compliance Manager, Information Protection, DLP, retention,
Records Management, Insider Risk, eDiscovery, and Audit.

[Microsoft Purview
Documentation](https://learn.microsoft.com/en-us/purview/)

## 🧠 Microsoft Security Platform

Once you understand the individual products, see how Microsoft's
security services work together.

[Microsoft Security
Platform](https://learn.microsoft.com/en-us/security/zero-trust/security-platform)

Think:

``` text
IDENTITY
+
DEVICES
+
APPLICATIONS
+
INFRASTRUCTURE
+
SECURITY OPERATIONS
+
DATA
```


## 🚀 After SC-900

SC-900 is a fundamentals certification. Use it to identify which area
interests you:

``` text
Identity & Access
Security Operations
Azure Security
Microsoft 365 Security
Compliance
Endpoint Security
Cloud Security
```

## ⚠️ Keep Resources Current

Before relying on older material, ask:

``` text
Is the product name current?
Is the feature supported?
Has the portal changed?
Has the SC-900 exam changed?
```
