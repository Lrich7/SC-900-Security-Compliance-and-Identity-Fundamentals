# 📦 SC-900 Resources

Welcome to the **SC-900 Resources** section.

This folder contains external learning resources that support the
**Microsoft SC-900 --- Security, Compliance, and Identity Fundamentals**
course.

The repository lessons, labs, and projects provide the main learning
path. These resources provide **additional explanations, official
documentation, videos, and continued study material**.

------------------------------------------------------------------------

# 🎯 Resource Goals

Use this section to:

-   Access official Microsoft SC-900 training
-   Review Microsoft documentation
-   Find additional video explanations
-   Explore Microsoft security products
-   Continue studying beyond the lessons
-   Verify current Microsoft terminology and features

------------------------------------------------------------------------

# 🎓 SC-900 Study Guide

The official Microsoft SC-900 study guide outlines the skills measured
by the certification exam.

The major areas include:

``` text
Security, Compliance &
Identity Concepts

Microsoft Security Solutions

Microsoft Compliance Solutions
```

Always use the current Microsoft study guide when preparing for the
certification because exam objectives can change.

# ☁️ Azure Access

Some Azure exploration may require an Azure environment.

Depending on current Microsoft offerings, learners may have access
through:

``` text
An Existing Organization
A Training Tenant
Microsoft Learn Exercises
An Azure Subscription
Current Microsoft Trial / Free Offers
```

Do not create paid resources simply to complete this course unless you
understand the possible charges. Most SC-900 concepts can be learned
without building a large Azure environment.
