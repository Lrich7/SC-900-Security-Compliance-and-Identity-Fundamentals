# 📘 SC-900 Lessons

Welcome to the **Lessons** section of the **SC-900 — Microsoft Security, Compliance, and Identity Fundamentals** training repository.

These lessons build from security fundamentals through Microsoft Entra, Microsoft security solutions, and Microsoft compliance solutions.

---

# 🎯 How to Use the Lessons

```text
Read the Lesson
      ↓
Review Key Concepts
      ↓
Complete the Lab (when useful)
      ↓
Answer the Knowledge Check
      ↓
Continue
```

Not every lesson requires a lab. Labs are included when hands-on work, portal exploration, or a scenario adds meaningful value.

## 🧪 Lab Types

| Type | Purpose |
|---|---|
| 🟢 **Hands-On** | Create, configure, or test something |
| 🔵 **Explore the Tool** | Navigate a Microsoft portal or service and learn its important areas |
| 🟡 **Scenario** | Apply concepts to a fictional business or security situation |
| ❌ **No Lab** | The topic is better reinforced through examples and knowledge checks |

# 🗺️ Course Roadmap

## 🧠 Part 1 — Security, Compliance & Identity Concepts

### 📘 Lesson 01 — Security, Compliance & Identity Fundamentals
Security, compliance, identity, authentication, authorization, identity providers, CIA triad, SSO, federation, and GRC.

**Lab:** ❌ No dedicated lab

### 📘 Lesson 02 — Shared Responsibility, Defense in Depth & Zero Trust
Shared responsibility, defense in depth, Zero Trust, encryption, hashing, data residency, sovereignty, and privacy.

**Lab:** 🟡 Scenario — Apply Zero Trust

---

## 👤 Part 2 — Microsoft Entra

### 📘 Lesson 03 — Microsoft Entra ID & Identity Types
Microsoft Entra ID, tenants, directories, cloud identities, hybrid identities, external identities, devices, and workload identities.

**Lab:** 🔵 Explore the Tool — Microsoft Entra admin center

### 📘 Lesson 04 — Users, Groups & Identity Management
Users, groups, membership, external users, administrative roles, and identity management.

**Lab:** 🟢 Hands-On / 🔵 Explore the Tool

### 📘 Lesson 05 — Authentication & Multifactor Authentication
Authentication methods, MFA, security defaults, password protection, and authentication strength.

**Lab:** 🔵 Explore the Tool — Authentication & MFA

### 📘 Lesson 06 — Passwordless Authentication
Windows Hello for Business, passkeys/FIDO2, Microsoft Authenticator, and authentication method policies.

**Lab:** 🔵 Explore the Tool — Passwordless Authentication

### 📘 Lesson 07 — Conditional Access & RBAC
Conditional Access, signals, conditions, access controls, RBAC, and least privilege.

**Lab:** 🔵 Explore the Tool — Conditional Access

### 📘 Lesson 08 — Identity Governance & Protection
Access reviews, entitlement management, Privileged Identity Management, Identity Protection, and identity risk.

**Lab:** 🔵 Explore the Tool — Identity Governance & Protection

---

## 🛡️ Part 3 — Microsoft Security Solutions

### 📘 Lesson 09 — Azure Infrastructure Security
Virtual Networks, NSGs, Azure Firewall, WAF, DDoS Protection, Azure Bastion, and Key Vault.

**Lab:** 🔵 Explore the Tool — Azure Security

### 📘 Lesson 10 — Microsoft Defender for Cloud
Cloud security posture, secure score, recommendations, regulatory compliance, and workload protection.

**Lab:** 🔵 Explore the Tool — Microsoft Defender for Cloud

### 📘 Lesson 11 — Microsoft Defender XDR
Extended Detection and Response, the Microsoft Defender portal, alerts, incidents, investigation, and automated response.

**Lab:** 🔵 Explore the Tool — Microsoft Defender XDR

### 📘 Lesson 12 — Microsoft Defender Security Services
Defender for Endpoint, Office 365, Identity, Cloud Apps, Vulnerability Management, and Threat Intelligence.

**Lab:** 🟡 Scenario — Choose the Defender Service

### 📘 Lesson 13 — Microsoft Sentinel
SIEM, SOAR, data connectors, analytics, incidents, investigation, and automation.

**Lab:** 🔵 Explore the Tool — Microsoft Sentinel

---

## 📋 Part 4 — Microsoft Compliance Solutions

### 📘 Lesson 14 — Microsoft Purview & Compliance
Microsoft Purview, Compliance Manager, compliance score, improvement actions, regulatory requirements, and Service Trust Portal.

**Lab:** 🔵 Explore the Tool — Microsoft Purview

### 📘 Lesson 15 — Information Protection, DLP & Data Lifecycle
Data classification, sensitivity labels, Data Loss Prevention, retention, records management, and data lifecycle.

**Lab:** 🔵 Explore the Tool / 🟡 Scenario — Protect Information

### 📘 Lesson 16 — Insider Risk, eDiscovery & Audit
Insider Risk Management, eDiscovery, Audit, investigations, and compliance monitoring.

**Lab:** 🔵 Explore the Tool — Investigations & Compliance

# 🧠 What to Focus On

SC-900 is a fundamentals certification. For each technology, ask:

```text
WHAT is it?

WHAT problem does it solve?

WHO or WHAT does it protect?

WHEN would an organization use it?

WHICH Microsoft platform provides it?
```

A useful high-level map:

```text
Microsoft Entra
=
Identity & Access

Microsoft Defender
=
Security & Threat Protection

Microsoft Sentinel
=
Security Operations

Microsoft Purview
=
Data Security & Compliance
```
