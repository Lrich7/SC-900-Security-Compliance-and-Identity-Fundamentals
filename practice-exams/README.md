# 📝 SC-900 Practice Exams

Welcome to the **SC-900 Practice Exams** section.

These exams are designed to test the concepts covered throughout the
lessons, labs, and projects in this repository. They emphasize
**recognizing Microsoft security technologies, understanding their
purpose, and choosing the right solution for a scenario**.

------------------------------------------------------------------------

# 🎯 Exam Goals

Use the practice exams to:

-   Check your understanding without looking at notes
-   Identify weak lessons before the certification exam
-   Practice Microsoft product and feature selection
-   Reinforce important SC-900 terminology
-   Practice scenario-based thinking
-   Build confidence before using Microsoft's official Practice
    Assessment

# 🧠 How to Use a Practice Exam

Take the exam **closed-book** first.

``` text
ANSWER QUESTION
      ↓
MARK UNSURE ITEMS
      ↓
FINISH EXAM
      ↓
CHECK ANSWER KEY
      ↓
REVIEW MISSED TOPICS
```

Do not just memorize the correct answer. Make sure you can explain **why
the other choices do not fit the requirement**.

------------------------------------------------------------------------

# 📊 Scoring

These repository exams use simple percentage scoring for study purposes.

``` text
90–100% → Excellent review level
80–89%  → Strong; review missed topics
70–79%  → Good progress; more review recommended
Below 70% → Revisit weak lessons before moving on
```

Microsoft certification exams use scaled scoring, so these percentages
are **not a prediction of your official exam score**.

# 🎯 Final Advice

For SC-900, focus on four questions:

``` text
WHAT IS THE SERVICE?

WHAT PROBLEM DOES IT SOLVE?

WHEN WOULD I USE IT?

HOW IS IT DIFFERENT FROM
A SIMILAR MICROSOFT SERVICE?
```

And remember:

``` text
ENTRA    → Identity & Access
DEFENDER → Threat Protection
SENTINEL → Security Operations
PURVIEW  → Data Security & Compliance
```
