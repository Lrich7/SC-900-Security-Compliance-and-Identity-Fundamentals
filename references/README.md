# 📚 SC-900 References

Welcome to the **SC-900 References** section.

This folder contains quick-reference material for the **Microsoft SC-900
--- Security, Compliance, and Identity Fundamentals** course. The
lessons explain concepts in detail; these files are designed for **quick
review, comparison, and exam preparation**.

------------------------------------------------------------------------

# 🎯 Reference Goals

Use these files to:

-   Review important SC-900 terminology
-   Compare Microsoft security products
-   Refresh concepts before practice exams
-   Reinforce common exam distinctions
-   Quickly review Entra, Defender, Sentinel, Purview, and Zero Trust

------------------------------------------------------------------------

# 📖 Reference Guide

## 📖 Glossary

Important SC-900 terms and definitions, including concepts such as
authentication, authorization, Conditional Access, Zero Trust, RBAC,
SIEM, SOAR, DLP, eDiscovery, and identity governance.

## 📝 Cheat Sheet

A condensed review for quick study, exam preparation, product
recognition, and last-minute refreshes.

## 🎯 Exam Tips

Tips for recognizing common SC-900 question patterns and identifying
what a question is really asking.

## 👤 Microsoft Entra Reference

Quick review of users, groups, external identities, authentication, MFA,
passwordless, Conditional Access, RBAC, Identity Protection, PIM, Access
Reviews, Entitlement Management, and lifecycle concepts.

``` text
MICROSOFT ENTRA
=
IDENTITY & ACCESS
```

## 🛡️ Microsoft Defender Reference

Quick comparison of Defender for Cloud, Endpoint, Office 365, Identity,
Cloud Apps, Vulnerability Management, and Defender XDR.

## 🏷️ Microsoft Purview Reference

Quick review of Compliance Manager, Information Protection, sensitivity
labels, DLP, retention, Records Management, Insider Risk, eDiscovery,
Audit, and Communication Compliance.

## 🔐 Zero Trust Reference

Focused review of:

``` text
VERIFY EXPLICITLY
USE LEAST PRIVILEGE
ASSUME BREACH
```

along with Defense in Depth and Shared Responsibility.
