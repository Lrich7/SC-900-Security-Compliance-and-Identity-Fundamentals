# 🧪 SC-900 Labs

Welcome to the **SC-900 Labs** section.

These labs support the lessons in the **SC-900 Security, Compliance, and
Identity Fundamentals** course and provide practical ways to reinforce
the concepts covered in each lesson.

The labs are designed for beginners and focus on understanding **what
Microsoft security tools do, where to find them, and when to use them**.

------------------------------------------------------------------------

# 🎯 Lab Goals

The labs help you:

-   Explore Microsoft security and compliance portals
-   Recognize important tools and features
-   Connect SC-900 concepts to real-world IT scenarios
-   Practice choosing the correct Microsoft solution
-   Gain familiarity without making unnecessary production changes

------------------------------------------------------------------------

# 🧪 Lab Types

Not every SC-900 topic needs the same kind of lab.

  -----------------------------------------------------------------------
  Type                                Purpose
  ----------------------------------- -----------------------------------
  🟢 **Hands-On Lab**                 Create or configure something in a
                                      safe environment

  🔵 **Explore the Tool**             Navigate a Microsoft portal and
                                      locate important features

  🟡 **Scenario Lab**                 Solve a fictional business or
                                      security problem

  ❌ **No Lab**                       The lesson is primarily conceptual
                                      and does not benefit from a
                                      separate lab
  -----------------------------------------------------------------------

Most portal exploration labs are intentionally **read-only** so they can
be followed safely in an existing Microsoft environment.

------------------------------------------------------------------------

# ⚠️ Production Environment Notice

Some labs reference Microsoft Entra, Azure, Defender, Sentinel, or
Purview.

If you are using a production environment:

``` text
READ
EXPLORE
OBSERVE
```

Do not create, delete, or modify production settings unless you are
authorized and understand the impact.

Licensing, permissions, tenant configuration, and Microsoft portal
updates may cause your environment to look slightly different from the
examples.

# 📚 Lab Roadmap

## Part 1 --- Security, Compliance & Identity Concepts

### 🧪 Lab 02 --- Apply Zero Trust

**Type:** 🟡 Scenario Lab

Apply the Zero Trust principles of **Verify Explicitly, Use Least
Privilege, and Assume Breach** to a fictional organization.

------------------------------------------------------------------------

## Part 2 --- Microsoft Entra

### 🧪 Lab 03 --- Explore Microsoft Entra ID

**Type:** 🔵 Explore the Tool

Explore the Microsoft Entra admin center and locate users, groups,
devices, applications, roles, Conditional Access, Identity Protection,
and Identity Governance.

### 🧪 Lab 04 --- Users & Groups

**Type:** 🟢 Hands-On / 🔵 Explore the Tool

Explore users and groups and, when using an authorized test environment,
practice creating a test user and security group.

### 🧪 Lab 05 --- Explore Authentication & MFA

**Type:** 🔵 Explore the Tool

Explore authentication methods, Microsoft Authenticator, MFA,
authentication strengths, Security Defaults, and related authentication
settings.

### 🧪 Lab 06 --- Explore Passwordless Authentication

**Type:** 🔵 Explore the Tool

Explore passkeys/FIDO2, Windows Hello for Business, Microsoft
Authenticator, Temporary Access Pass, and passwordless authentication
concepts.

### 🧪 Lab 07 --- Explore Conditional Access & RBAC

**Type:** 🔵 Explore the Tool + 🟡 Scenario Lab

Explore Conditional Access and role-based access control, then apply
them to common access-control scenarios.

### 🧪 Lab 08 --- Explore Identity Governance & Protection

**Type:** 🔵 Explore the Tool + 🟡 Scenario Lab

Explore Identity Protection, PIM, Access Reviews, Entitlement
Management, and identity lifecycle concepts.

------------------------------------------------------------------------

## Part 3 --- Microsoft Security Solutions

### 🧪 Lab 09 --- Explore Azure Infrastructure Security

**Type:** 🔵 Explore the Tool

Explore Azure security controls such as NSGs, Azure Firewall, DDoS
Protection, Azure Bastion, Key Vault, Azure Policy, and Azure RBAC.

### 🧪 Lab 10 --- Explore Microsoft Defender for Cloud

**Type:** 🔵 Explore the Tool

Explore cloud security posture, recommendations, Secure Score, workload
protection, and Defender for Cloud concepts.

### 🧪 Lab 11 --- Explore Microsoft Defender XDR

**Type:** 🔵 Explore the Tool

Explore incidents, alerts, evidence, Advanced Hunting, and the unified
Microsoft Defender experience.

### 🧪 Lab 12 --- Choose the Defender Service

**Type:** 🟡 Scenario Lab

Practice choosing between Defender for Endpoint, Defender for Office
365, Defender for Identity, Defender for Cloud Apps, and related
security services.

### 🧪 Lab 13 --- Explore Microsoft Sentinel

**Type:** 🔵 Explore the Tool

Explore Sentinel concepts including data connectors, analytics,
incidents, hunting, workbooks, automation, and playbooks.

------------------------------------------------------------------------

## Part 4 --- Microsoft Compliance Solutions

### 🧪 Lab 14 --- Explore Microsoft Purview

**Type:** 🔵 Explore the Tool

Explore Compliance Manager, Information Protection, DLP, Data Lifecycle
Management, Records Management, eDiscovery, Audit, and Insider Risk
Management.

### 🧪 Lab 15 --- Protect and Govern Contoso Data

**Type:** 🟡 Scenario Lab

Design classification, sensitivity labeling, DLP, retention, and
records-management controls for fictional Contoso data.

### 🧪 Lab 16 --- Investigate Risk & Compliance Events

**Type:** 🟡 Scenario Lab

Choose between Insider Risk Management, eDiscovery, Audit, and
Communication Compliance during investigation scenarios.

# 📝 Lab Naming

All lab files use the same naming format:

``` text

```

``` text
🟢 Hands-On
🔵 Explore the Tool
🟡 Scenario
```

This keeps the files visually consistent and sorted by lab number.
