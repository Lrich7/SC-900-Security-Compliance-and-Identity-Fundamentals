# ✅ Suggested Answers

``` text
Compliance Score
→ Measures progress toward
  recommended compliance actions

Improvement Action
→ Recommended work that can
  improve compliance posture

Information Protection
→ Discover, classify, protect data

DLP
→ Prevent inappropriate use/sharing

Data Lifecycle Management
→ Manage retention/deletion

Records Management
→ Govern official records

eDiscovery
→ Legal/investigative content

Audit
→ User/admin activity

Insider Risk Management
→ Potential internal risk
```

Service Trust vs Compliance Manager:

``` text
Audit/trust documentation
→ Service Trust Portal

Improvement actions
→ Compliance Manager

Compliance Score
→ Compliance Manager

Microsoft compliance practices
→ Service Trust Portal
```
