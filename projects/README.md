# 🏗️ SC-900 Projects

Welcome to the **SC-900 Projects** section.

The projects are larger exercises that combine concepts from multiple
lessons into realistic security, identity, and compliance scenarios.

Unlike individual labs, projects are designed to make you think about
**how multiple Microsoft technologies work together**.

------------------------------------------------------------------------

# 🎯 Project Goals

The projects help you:

-   Apply concepts from multiple SC-900 lessons
-   Practice choosing the correct Microsoft technologies
-   Design security strategies for realistic organizations
-   Connect identity, security, operations, and compliance
-   Prepare for scenario-based certification questions
-   Understand how Microsoft security products work together

No production configuration is required.

# 🏗️ Project 01 --- Secure an Organization's Identity Environment

**Covers:** Lessons 01--08

Design a secure identity environment for a fictional organization using
Microsoft Entra and Zero Trust principles.

Topics include:

``` text
Zero Trust
Users & Groups
External Identities
Authentication
MFA
Passwordless Authentication
Conditional Access
RBAC
Identity Protection
PIM
Access Reviews
Entitlement Management
Identity Lifecycle
```

The goal is to understand how Microsoft Entra controls **who can access
resources and under what conditions**.

------------------------------------------------------------------------

# 🏗️ Project 02 --- Build a Microsoft Security Strategy

**Covers:** Lessons 09--13

Design a layered Microsoft security strategy for Azure and Microsoft
365.

Topics include:

``` text
Azure Infrastructure Security
Network Security
Key Vault
Azure Policy
Microsoft Defender for Cloud
Cloud Security Posture
Microsoft Defender Security Services
Microsoft Defender XDR
Microsoft Sentinel
SIEM
SOAR
Security Investigation
Automation
```

The goal is to understand how Microsoft security services **protect
workloads, detect threats, correlate attacks, and support security
operations**.

------------------------------------------------------------------------

# 🏗️ Project 03 --- Build a Compliance & Data Protection Strategy

**Covers:** Lessons 14--16

Design a Microsoft Purview strategy for protecting and governing
organizational data.

Topics include:

``` text
Service Trust Portal
Compliance Manager
Compliance Score
Information Protection
Sensitive Information Types
Sensitivity Labels
DLP
Endpoint DLP
Data Lifecycle Management
Retention
Records Management
Insider Risk Management
eDiscovery
Audit
Communication Compliance
```

The goal is to understand how Microsoft Purview helps organizations
**classify, protect, govern, retain, and investigate data**.

The challenge includes:

``` text

Governance

SIEM / SOAR
```

# 🧠 Four-Platform Memory Map

Throughout the projects, remember:

``` text
WHO CAN ACCESS?
→ Microsoft Entra

WHAT IS ATTACKING US?
→ Microsoft Defender

→ Microsoft Sentinel
```

# 📝 How to Complete a Project

For each requirement:

``` text
1. IDENTIFY THE PROBLEM

2. IDENTIFY THE SECURITY,
   IDENTITY, OR COMPLIANCE GOAL

3. CHOOSE THE MICROSOFT
   TECHNOLOGY

4. EXPLAIN WHY IT FITS

5. CONNECT IT TO THE
   LARGER ARCHITECTURE
```

Try answering the questions before reviewing the suggested solution.

# 🎓 After the Projects

After completing all four projects, move to the practice exams.

Recommended order:

``` text
Practice Exam 1
→ Lessons 01–08

Practice Exam 2
→ Lessons 09–16

Final Exam
→ Lessons 01–16
```

The projects are especially useful before the exams because they
reinforce **product selection and scenario recognition** rather than
simple memorization.
